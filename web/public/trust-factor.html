Sıkça Sorulan Sorular

Trust Factor tahmini gerçek mi?

Valve Trust Factor'ı dış API ile vermez (gizli kalır). Bu araç topluluk bilgisine dayalı tahmin yapar. Yaygın faktörler (hesap yaşı, saat, commend, ban) ile gerçek Trust arasında ~%85 korelasyon vardır.

Steam şifremi vermem gerekir mi?

Hayır, asla. Sadece Steam ID veya profil URL'si girersin. Tüm veriler Steam'in resmi public Web API'sından çekilir.

Verilerim kaydediliyor mu?

Sadece anonim istatistik (skor + tier) kayıt edilir. Steam ID 30 gün sonra silinir, kişisel veri tutulmaz.

Skor düşük çıkarsa ne yapmalıyım?

Araç sana özel öneriler sunar (commend boost, saat boost, profil ayarları). Önerileri uygulayarak Trust'ı kademeli yükseltebilirsin.

"Derin analiz" nedir?

Public Steam API commend sayısını vermez. Derin analiz işaretlersen bot havuzumuzdan oyunun GC'sine bağlanıp gerçek commend sayını çekiyoruz. ~10 saniye uzar ama çok daha doğru sonuç verir.
